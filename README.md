# StreamStats

Потоковый анализатор логов в форматах CSV и JSONL. Программа читает файлы построчно, не загружая их целиком в оперативную память (используются генераторы), валидирует данные и формирует статистический отчет в формате JSON.

## Возможности

- Потоковая обработка: чтение файлов любого размера без переполнения памяти.
- Поддержка форматов: CSV (с заголовками) и JSONL.
- Валидация: строгая проверка обязательных полей (время в ISO 8601, уровни логирования).
- Обработка ошибок: режим строгой остановки при битой строке или режим пропуска с логированием (--skip-invalid).
- Агрегация: подсчет общего числа событий, распределение по уровням, источникам и топ-5 источников с ошибками.
- Мультифайловый анализ: объединение статистики из нескольких файлов в один отчет.

## Установка

Требуется Python 3.11 или выше.

```bash
git clone https://github.com/your-username/streamstats.git
cd streamstats
pip install -e .
```

## Использование

```bash
python -m streamstats analyze <ФАЙЛЫ...> --format <csv|jsonl> --output <ОТЧЕТ.json>
```

Пример анализа одного файла:
```bash
python -m streamstats analyze app.log.csv --format csv --output report.json
```

Пример анализа нескольких файлов и пропуска битых строк:
```bash
python -m streamstats analyze data1.jsonl data2.jsonl --format jsonl --output report.json --skip-invalid
```

## Структура отчета

Программа создает JSON-файл, содержащий:
- total — общее количество валидных событий.
- by_level — количество событий по уровням (DEBUG, INFO, WARNING, ERROR, CRITICAL).
- by_source — количество событий по источникам.
- top_errors — топ-5 источников с наибольшим числом ошибок (ERROR/CRITICAL).
- first_timestamp / last_timestamp — время первого и последнего события.
- skipped — количество пропущенных невалидных строк.
